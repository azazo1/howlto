# howlto v0.5.0

Date: 2026-08-22

本版本新增可恢复的交互式会话, 加强配置和日志管理, 并改善命令生成与执行体验. 现有配置会继续加载, 新增配置项会使用默认值.

## Highlights

- 无参数启动现在可以进入多轮交互会话, 并从历史会话继续工作.
- 会话数据按工作目录持久化, 同时提供保留数量, 生命周期和总大小限制.
- 配置文件增加版本和迁移保护, 降低配置结构升级带来的风险.
- 日志文件会按日期轮换并自动清理, 避免长期运行持续占用磁盘空间.

## Upgrade Notes

1. 升级前无需手动修改已有配置文件.
2. 首次启动时会自动补充缺失的配置版本字段.
3. 如不需要历史会话, 可以删除配置目录下的 sessions 子目录.
4. 使用 `howlto --version` 检查版本是否显示为 `v0.5.0` 或带构建 commit 的版本.

## Features

- 新增无参数启动的交互式聊天, 支持输入多个 prompt 并查看历史响应.
- 新增会话菜单, 可以创建新会话或恢复当前工作目录下的历史会话.
- 新增会话保留策略, 支持按目录数量, 总字节数和天数清理旧数据.
- 配置加载增加版本字段和迁移模块, 为后续配置变更提供明确入口.
- 日志增加按日期命名, 过期文件清理和总容量限制.
- prompt 处理可以更准确地区分命令候选和文本回答的请求身份.

## Bug Fixes

- 限制滚动字符输出速度, 减少快速流式输出导致的界面拥挤.
- 降低命令执行超时, 避免外部命令长时间阻塞响应.
- 修复流式响应和多轮工具调用中的状态处理问题.
- 会话文件使用原子写入并设置受限权限, 降低写入中断和本地误读风险.
