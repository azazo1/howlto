# howlto v0.6.0

Date: 2026-09-27

本版本可以给思考模型指定 reasoning_effort, 并修正提权确认框对多行命令的展示. 现有配置会继续加载, 不写该字段时请求内容与上一版本一致.

## Highlights

- 可以在 `config.toml` 的 `[llm]` 中设置 `reasoning_effort`, 该值会原样发给兼容的模型.
- 不设置或留空时不发送这个参数, 原来的模型调用保持不变.
- 提权确认框会按命令行数和折行增高, 并保留命令原有缩进.

## Upgrade Notes

1. 升级前无需修改已有 `config.toml` 或 `profiles.toml`.
2. 需要控制思考强度时, 增加 `[llm].reasoning_effort`, 例如 `"low"`. 取值会原样发送, 可用值以模型提供商为准.
3. 模型调用外部命令时, 超时仍限制在 1 到 10 秒. 本版本只是把默认值和说明改成与这个上限一致.
4. 发布构建的 `howlto --version` 应显示 `v0.6.0`. 不经 `just dist` 或 CI 的本地开发构建显示 `dev-build`.

## Features

- LLM: 新增可选的 `reasoning_effort`, 回答请求和收尾请求都会带上.
- 日志: 创建 AnswerAgent 时记录模型名和接口主机, 不记录完整 URL.

## Bug Fixes

- 提权确认: 多行命令不再被压成一行, 超长命令会在对话框宽度内折行, 并保留原有缩进.
- 日志: 修正模型名和接口主机在 span 中的显示格式.
- 外部命令: 超时默认值从 30 秒改为 10 秒, 与原有的 10 秒上限一致. 实际等待时间与上一版本相同.
