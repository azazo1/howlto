# howlto v0.3.0

本版本改进了 agent 的结果输出和外部工具执行稳定性. 命令候选在选择后仍可查看, 工具日志更易读, 同时加强了多步骤命令和文本回答的生成规则.

## Highlights

- 命令选择会在 TUI 前持久输出全部候选项, 并使用明确边界区分多个候选和单条多行命令.
- info 日志按具体工具的调用语义展示参数, 例如 `explore: ls`. 完整 JSON 参数仅保留在 debug 日志中.
- 流式进度信息不再展示工具调用 JSON, 但原始内容仍保留在 agent 历史中.
- `explore`, `man`, `tldr`, `thefuck` 和 `elevate` 的外部命令增加 20 秒超时, 防止交互式或不退出的进程阻塞 agent.
- `man` 管道并发处理 stdout 和 stderr, 避免输出较大时发生管道死锁.
- 每个命令候选会作为可独立执行的完整方案生成. 多步骤流程会组合到同一候选中, 不再拆成只能单独选择的不完整步骤.
- agent 会优先使用 PATH 中的 `fd` 和 `rg`, 文本回答也可以附带完整且可复现的命令.
- 文档新增当前状态查询和解释类问题的直接回答示例.
- CI 和 release 共用 6 项 Linux/macOS 构建矩阵. Tag 发布会校验 Cargo 版本, annotated tag 和人工说明, 并为全部归档生成 `SHA256SUMS`.

## Upgrade Notes

- 无需迁移现有配置.
- Cargo package version 已更新为 `0.3.0`.
